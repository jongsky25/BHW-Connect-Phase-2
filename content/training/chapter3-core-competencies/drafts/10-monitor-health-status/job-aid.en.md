# Monitor health status

- Check the device and suitable cuff. Ask permission and prepare the person using the approved checklist. Measure and repeat if the protocol requires it. Record the actual reading, units, time and context. Tell the midwife the result and any concern.
- Measure, record, and report pulse using the approved protocol.
- Measure and record both accurately.
- Perform and document measurement with dignity and assistance where needed.
- Plot correctly and identify whether qualified review is needed.
- Measure and record MUAC and identify the reviewed referral action.
- Calculate or plot using the correct approved tool and state a safe follow-up.
