# C1AF-11 — Prepare and Run lesson 1.6.2

This increment adds read-only Prepare and Run views for the published 1.6.2 lesson, “Ask and clarify.” An active, non-preview assessor can open Prepare from the Chapter 1 working area, including a selected BHW. The return URL preserves search, area, learning status, page and selected learner. The lesson route accepts only the same program's workspace path as a return destination. Prepare, Run and the existing BHW presentation retain that URL when switching.

The compact cards cite the current guide's section IDs: Prepare uses `time-materials`, `prepare` and `opening`; Run uses `steps`, `practice`, `misconception` and `observe`. The objective comes from the published lesson. Both views render the same published lesson observation indicator at `objective_index: 0`; they do not join it to a module indicator or claim a new canonical criterion ID. The complete published guide, activity library, levels, source and review details remain expandable. The Run view also exposes the full exit check and next action. The compact time note distinguishes suggested guided delivery (90 minutes), personal reading (10–13 minutes) and optional story or replay.

## Handoff recording validation

Opening Prepare, Run, the full guide or the BHW presentation makes no Chapter 1 observation, assessment, activity plan, session, delivery, award or learner progress write. Run says to record exact words, round, observer and prompts, and to arrange later direct observation for anyone not seen. This is instructional text only: there is no recording action or implied grade. An unseen performance remains *not observed*. C1AF-13 defines the guarded practice evidence contract; C1AF-14 adds the lesson-to-observation recording UI after that contract exists.

Focused tests cover both languages, criterion/objective consistency, missing guide content, workspace filter and learner return context, and external return URL rejection. Before release, walk through on a phone and tablet with keyboard navigation and stable pilot accounts; confirm the complete guide and BHW presentation remain usable when optional media are absent. Record any editorial wording change against the cited guide section before expanding this template to 1.1–1.9.

## Remaining policy gaps

The Chapter 1 mapping/rubric, simulation, issuer and award rules still require owner approval before activation. C1AF-09 restoration/revocation, historical evidence equivalence and trusted conversion remain open. This view does not alter the current rollout flags or grant official action authority.

## C1AF-12 boundary

C1AF-12 starts at saved activity plans and session handoff: select an existing owned session or create a draft, save chosen activities with snapshots, support ad hoc practice, and reuse attendance, delivery and activity records. It must preserve guide-to-session return context, avoid duplicate sessions on retry, respect completed/cancelled immutability, and make no automatic progress or certification change. No part of that save or handoff contract is implemented here.
