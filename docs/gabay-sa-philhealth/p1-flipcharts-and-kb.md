## KB entry inventory

This inventory is for the **published Knowledge Base** and Chat Guide. Final entries should be short, bilingual, cite the relevant claim/source, and give a next action. Keywords must be distinctive; test each against the existing UHC entries before publication. IDs are proposed stable content IDs.

**Clarifier for `register` / `rehistro` / `magparehistro`:** If the question lacks a PIN, clinic, or dependent/transfer clue, ask: **“Do you mean a PhilHealth PIN/member record or choosing a YAKAP clinic?” / “PhilHealth PIN o rekord ba, o pagpili ng YAKAP clinic?”** Route the answer to the relevant published entry. If context is already clear, do not ask again.

**Retrieval fixture plan:** At least three independent phrasings per entry: Filipino, English, and Taglish; additional misspellings for PIN, YAKAP, and GAMOT; negative cases for dose, stock, records, and vague registration. Include the existing UHC entries in the candidate corpus so a generic “PhilHealth” keyword does not win over a more specific YAKAP question. Target ID and expected result type must be reviewed with each fixture.
