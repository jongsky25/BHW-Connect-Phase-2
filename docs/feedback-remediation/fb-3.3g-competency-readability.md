## Confirmed problem and bounded fix

The actual component, app CSS and repository-authored HEPO competency notes reproduced two light-theme contrast failures at 320px/XL: indicator/objective captions at 4.01:1 and the competency-statement caption at 4.43:1, below the required 4.5:1. The pane showed objectives, observable criteria, insufficient evidence and all three detailed level descriptions for every indicator together. Small uppercase rubric labels and nested padding further limited scanning on a phone.

The competency pane now separates each numbered heading, objective, observable criterion and insufficient-evidence criterion into clear blocks. All criterion and rubric text uses at least the normal 16px base size, scales with user text size, and uses ink text rather than low-opacity captions or long red/green paragraphs. Colored borders and level backgrounds supplement explicit labels. Reduced phone padding preserves more reading width.

Full, unchanged three-level descriptions live inside a native **Compare the three levels** disclosure for each indicator, closed initially. Keyboard activation opens it without an API call. Full comparisons stay stacked until the desktop breakpoint to avoid narrow tablet columns. Other lesson-guide IndicatorCards retain their existing always-visible comparison layout.

A bilingual **Jump to an indicator** navigation appears for multiple indicators. Native fragment links focus the actual numbered cards and scroll them below the responsive sticky header. Single/missing-indicator cases get no invented shortcuts; missing objectives get no fabricated content. Missing-note text has adequate contrast.

No authored statement, objective, criterion, level description or approved lesson/media text is shortened, rewritten or deleted. Existing source diagrams were considered: they illustrate roles, service and record flows, contain teaching-specific labels and do not directly depict all four observation criteria. This change does not duplicate them as competency evidence or add decorative stock imagery. The illustration/content portion of the broad report is not claimed resolved.
