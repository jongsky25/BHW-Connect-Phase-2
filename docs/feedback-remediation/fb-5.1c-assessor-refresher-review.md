# FB-5.1c — optional assessor refresher review and study pace

Report `cbcf1baf-0c7a-4341-9817-83b1899455db` asks for a refresher beside basic training and suggests deadlines/duration limits or a daily lesson cap. It was submitted on the Chapter 1 HEPO personal-study lesson. A read-only pilot query on 25 October 2026 confirms the wording, no screenshot, and unchanged `new` status.

## Merit and decision

Returning assessors have a useful need to revisit material without losing earned progress. The existing chapter list already permits reviewing completed lessons, and `chapterStudy` matches personal completion to each currently published revision. The missing piece is an explicit refresher entry point. This increment provides that navigation over existing published chapter lessons; it does not claim a separately authored refresher curriculum, reduced qualification path or certification renewal.

The request provides no proposed time limit, daily number, rationale or evidence that blocking additional study would improve learning. Personal study currently has no daily cap or lesson countdown; the approved Chapter 1 assessment flow is untimed with saved answers and optional breaks ([FB-5.1a](fb-5.1a-assessment-length-and-breaks.md)). Mandatory deadlines/caps are not introduced. Practical assessment already has an agreed arrangement in the Chapter 1 working area. This increment explains that formal assessment still follows its agreed schedule and requirements rather than applying a new deadline to personal reading. It makes no promise about local training schedules.
