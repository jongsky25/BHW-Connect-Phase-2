# AF-05 — Chapter qualification and My qualifications

AF-05 issues a Chapter I assessor qualification automatically when the server records a passing AF-04 scoring exercise. The issuance trigger checks the signed-in assessor, active account, published chapter and course, assigned area, current AF-03 pretest, all current Chapter I lesson revisions, passing post-test, all six current orientation lessons, and a passing orientation attempt. The pass occurs without a practical assessment by another assessor. One row is issued per assessor, chapter, curriculum version, and orientation version, with the orientation attempt recorded as evidence. Repeated issuance requests return the same row and never reactivate a suspended or revoked qualification.

The **My qualifications** page shows each available chapter's status, next step, issue date, curriculum version, rubric version, and orientation version. The rubric version equals the reviewed curriculum version, which pins each source rubric hash in the assessor manifest. Chapter II remains unavailable until its exam bank and orientation are approved; a Chapter I qualification cannot satisfy Chapter II. A passing orientation recorded before AF-05 can be issued from the page's explicit recovery action after the server rechecks all evidence.

An admin can suspend, revoke, or restore a qualification in their assigned area with a required reason. Status changes and issuance are in the audit trail. Direct client writes to qualification and orientation evidence tables are denied. The public qualification predicate returns true only for an active assessor with an active qualification for the current chapter and matching curriculum and orientation versions. Later assessor increments can use this predicate; AF-10 will activate the stricter live assessment gates after the full path exists. Existing assessor accounts receive no automatic qualification.
